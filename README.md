
# Student Grade Calculator

A beginner-friendly Java console application that calculates the
average of three subject marks and assigns a letter grade.

## Features

- Accepts marks for three subjects
- Validates numeric input and mark ranges
- Calculates the average
- Assigns a letter grade

## Requirements

- Java Development Kit (JDK)

## Compile

```bash
javac GradeCalculator.java
```

## Run

```bash
java GradeCalculator
```

## Concepts Practiced

- Java variables and data types
- Methods and return values
- Scanner and user input
- Loops and conditional statements
- Arithmetic and input validation

## Grading Rules

- A: 90-100
- B: 80-89.99
- C: 70-79.99
- D: 60-69.99
- F: below 60
